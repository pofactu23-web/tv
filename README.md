# TV SPACE — готовый сайт с подключённым Яндекс Диском

Публичная папка: https://disk.yandex.ru/d/aSqXwCdbCigbFQ

**Файлы в папке на момент подключения:**
- `app-lite-release.apk` (Lampa)
- `TorrServe_MatriX.143.Client.apk`
- `televizo-default.apk`
- PDF-инструкция по установке TV SPACE

Обратите внимание: сейчас APK-файлы размещены **по отдельности**, а не в ZIP-архиве. Поэтому сайт предлагает скачать три APK и инструкцию отдельно.

## Проверить сайт локально
Откройте `index.html`. Кнопки «Скачать комплект» должны открывать указанную папку Яндекс Диска.

## Опубликовать на GitHub Pages
1. Создайте на GitHub репозиторий, например `tv-space`.
2. Загрузите в корень репозитория **`index.html` и `site-config.js`**.
3. Перейдите в `Settings → Pages`, установите `Deploy from a branch`, `main`, `/(root)` и сохраните.
4. Дождитесь публикации и проверьте кнопку скачивания **с телефона**.
5. После получения реального адреса сайта сгенерируйте QR-код **на адрес сайта**, не на Яндекс Диск.

## Изменение Яндекс-ссылки
Откройте `site-config.js` и замените значение `window.TVSPACE_YANDEX_URL`. При изменении файла ссылка на сайте обновится после публикации.

## Важно
- APK предназначены для совместимых Android TV / Google TV, не для Samsung Tizen и LG webOS.
- Плееры не предоставляют автоматически каналы или доступ к платным фильмам; для просмотра нужны разрешённые источники.
- Убедитесь, что имеете право размещать и распространять конкретные APK.
